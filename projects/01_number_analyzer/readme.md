# Mini Project #1 - Number Statistics Analyzer 

In this project, applying concepts learned in Level 1-3 of my Python Algorithm course.

## Goal

Build a Python program that analyses user-entered numbers using loops, conditions, lists and arithmetic. 

## Project Requirments:

- Count the total numbers entered.
- Calculate their sum and average.
- Find the largest and smallest numnbers.
- Find the second-largest and second-smallest distinct numbers.
- Identify duplicate values.
- Identify values that occur exctly one.

## Concepts Practised

- Reading and splitting user input.
- Converting input into numbers.
- Loops and conditions statments.
- Counters and running totals.
- Tracking largest and smallest values.
- Lists and duplicates detection

## How to run

Requires Python 3.

Open a terminal inside this project folder and run:
    python number_analyzer.py 

Enter numbers seprated by space when prompted.

## Example

Input:

    4 2 4 8 6

Expected results:

| Calculation | Result |
|---|---|
| Total numbers | 5 |
| Sum | 24 |
| Average | 4.8 |
| Largest | 8 |
| Smallest | 2 |
| Second-largest distinct | 6 |
| Second-smallest distinct | 4 |
| Duplicate values | 4 |
| Values occurring exactly once | 2, 8, 6 |

“Distinct” means repeated copies count as one value when
finding the second-largest or second-smallest number.

## Cases to Check

- Numbers containing duplicates
- All numbers being the same
    - Negative numbers and zero
- Only one number
- Empty input
